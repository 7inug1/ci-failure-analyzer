# AI 협업 기록 쓰기

`docs/ai-log.md` 맨 아래에 `## 날짜 작업 이름` 항목을 하나 추가한다.

1. 맡긴 것: 방금 끝낸 작업이 무엇인지 한 줄로 적는다.
2. 완료 조건: 무엇이 되면 끝인지 적는다.
3. 확인한 방법: 실제로 실행해 확인한 것과 결과를 적는다. 확인하지 않은 것은 "미확인"으로 적는다.
4. AI가 틀린 곳: 틀렸거나 고친 곳을 적는다. 없으면 "없음".
5. 다음에 달리 맡길 점: 다음에 바꿀 지시가 있으면 적는다.

적은 뒤 `npx prettier --write docs`를 실행한다.
