# 0002. 테스트 도구

상태: 결정됨 (2026-11-18)

## 배경

연습 앱의 테스트를 실행하고, 결과를 파일(`report.xml`)로도 남겨야 한다.

## 결정

Jest와 `jest-junit`을 쓴다.

## 이유

- 이미 써 본 도구라 새로 배울 것이 없다.
- 멘토 가이드가 Jest와 `jest-junit` 기준이다.
- 도구를 바꿔도 이번 목적(실패 만들기와 분석)에는 이득이 없다.

## 버린 대안

- Vitest: 멘토님이 써도 된다고 했지만, 바꿀 이유가 없다.

## 결과

- 필요하면 나중에 바꾸고, 그때 새 기록을 추가한다.
