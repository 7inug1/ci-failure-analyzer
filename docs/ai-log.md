# AI 협업 기록

AI에게 맡긴 작업마다 목표, 완료 조건, 확인한 방법, AI가 틀린 곳을 적습니다.

## 2026-11-18 저장소 셋업

- 맡긴 것: `.gitignore`, README, AGENTS.md, lint와 포맷 설정, 결정 기록, 권한 설정
- 완료 조건: 빈 `.env`를 만들어도 `git status`에 안 보이고, `npm run lint`와 `npm run format -- --check`가 통과하며, 규칙 10개가 적혀 있음
- 확인한 방법: `.env`, `node_modules`, `report.xml`을 만들어 `git status`로 무시되는지 직접 확인함. lint 규칙(`==` 사용)을 어긴 파일을 만들어 실패하는지 확인함
- AI가 틀린 곳: 기획서의 `.gitignore` 샘플이 줄 끝 주석을 써서 `.env`가 무시되지 않았다. `.gitignore`는 줄 끝 주석을 지원하지 않아 주석을 별도 줄로 옮겨 고침. 확인하지 않았다면 키가 올라갈 뻔함
- 다음에 달리 맡길 점: 설정 파일의 문법은 만들기 전에 공식 문서나 실제 실행으로 먼저 확인하게 한다
